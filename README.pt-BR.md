# Kangeikai

*[Read in English](README.md)*

Espaço virtual de código aberto onde as pessoas se movem por um mapa 2D compartilhado e
conversam com quem estiver por perto — voz e vídeo conectam automaticamente por proximidade,
sem precisar abrir uma chamada manualmente.

## Sobre o nome

**歓迎会** (*kangeikai*) significa "festa de boas-vindas" em japonês — uma reunião feita para
receber alguém novo.

Pronúncia: **kan-guêi-kai** (aproximadamente /kaŋ.ɡeɪ.kaɪ/)

## Status

MVP em desenvolvimento ativo. Veja [`docs/mvp-plan.md`](docs/mvp-plan.md) para o escopo e a
stack do MVP.

## Reportando um bug ou sugerindo uma feature

Abra uma [nova issue](https://github.com/kangeikailabsio/kangeikai/issues/new) seguindo o
[template de issue](.github/ISSUE_TEMPLATE.md) (em inglês): marque se é um bug ou uma
melhoria/feature e preencha a seção correspondente. Para um bug, descreva o problema e como
replicá-lo; para uma melhoria, descreva o objetivo e os benefícios.
